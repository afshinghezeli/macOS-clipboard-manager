# Security

Spindle stores everything you copy, so security reports get priority.

Please report vulnerabilities privately: on this repository, open **Security → Report a vulnerability**. Don't open a public issue.

In scope, for example:

- clipboard contents leaking: to logs, to disk outside the app's container, or to other apps;
- items that should be ignored (password-manager copies, ignored apps) being stored anyway;
- pasting into a different app than the one shown;
- anything in the update path: the appcast, signatures, download URLs.

Only the latest release receives fixes. Spindle is maintained by one person, so expect an acknowledgement within a week. Reporters are credited in the release notes unless they prefer otherwise.
